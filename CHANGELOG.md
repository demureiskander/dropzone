# Changelog

## [Unreleased]

### Added — 2026-09-08

- Исследование функций, способов вызова и настроек Dropover по официальным источникам.
- Обзор пользовательских обсуждений с отделением исторических жалоб от текущего поведения.
- Спецификация MVP Dropzone и критерии приёмки.
- Предварительный технический план нативного macOS-приложения.
- README, CLAUDE.md и AGENTS.md с контекстом и правилами разработки.
- `.gitignore` для будущего Swift/Xcode-проекта и локальный Git-репозиторий на ветке `main`.

### Status

- Этап подготовки: приложение и UI ещё не реализованы; 13 UI-референсов получены.
- Dropzone — рабочее название, совпадающее с названием приложения Aptonic.

### Changed — 2026-09-08

- Уточнено визуальное направление по референсам; добавлен `docs/DESIGN.md`.
- Drop на notch с подсветкой приближения и обводкой приёма перенесён в MVP.
- В MVP включён плавный follow-режим с default on, сохраняемым переключателем и паузой при взаимодействии.
- Зафиксированы compact/grid/list, контекстное меню, обратная связь при hover и направление собственной иконки.
- Технический план дополнен notch/follow и проверкой доступных инструментов разработки.
- Локальные копии референсов исключены из Git.
