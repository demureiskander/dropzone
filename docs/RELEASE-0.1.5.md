# Dropzone 0.1.5

This alpha adds a first-run introduction to the core Dropzone workflow.

- New users see a concise onboarding for shaking, dropping and dragging files out.
- The onboarding explains that files stay local and originals remain in place.
- Russian is selected initially when macOS prefers Russian; other systems start in English.
- The language can be changed immediately and remains available in Settings.

The build targets Apple Silicon and macOS 13 or newer. It is ad-hoc signed and not notarized.
