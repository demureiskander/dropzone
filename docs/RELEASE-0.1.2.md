## Menu bar and Dock visibility

- Dropzone appears in both the menu bar and Dock by default.
- Settings → General includes independent Show in Menu Bar and Show in Dock switches. Changes apply immediately and persist across launches.
- If both icons are hidden, reopening Dropzone from Applications opens Settings.

### Update

```sh
brew update
brew upgrade --cask demureiskander/dropzone/demureiskander-dropzone
```
