# Dropzone 0.1.6

This alpha improves shelf interaction and drag completion.

- Returning a dragged file to the same shelf keeps the file and shelf visible.
- After dragging items elsewhere, the shelf stays visible while other items remain.
- Expanding and collapsing the shelf now animates smoothly.
- Clicking empty space in the expanded shelf clears the selection.

The build targets Apple Silicon and macOS 13 or newer. It is ad-hoc signed and not notarized.
