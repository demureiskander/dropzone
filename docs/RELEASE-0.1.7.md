# Dropzone 0.1.7

This alpha makes shelf expansion and collapse feel smoother.

- Window size and position now animate together with a smooth start and stop.
- Compact and expanded content crossfade during the transition.
- Pointer following waits briefly after the animation instead of pulling the shelf at the final frame.
- Homebrew removal now closes a running copy; `--zap` also clears Dropzone preferences.

The build targets Apple Silicon and macOS 13 or newer. It is ad-hoc signed and not notarized.
