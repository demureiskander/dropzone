## Selection improvements

- Shift-click selects every file between the anchor and the clicked item, in both grid and list views.
- Shift-click works in either direction and can extend or contract the range.
- Command-click adds or removes only the clicked file.
- Settings now display the version from the application bundle.

25 automated tests pass. Apple Silicon, macOS 13+. Apache-2.0. Ad-hoc signed; not notarized.
